# SCI Writing Workflow

先读取本仓库 [完整流程](../../docs/workflow.md)。若单独安装本skill，请同时保留仓库目录结构或提供该文档，不凭空补全缺失规则。

1. 识别综述与原研；核对目标期刊、输入材料和现有阶段。科学事实来自真实来源。
2. 按流程交付目录/逻辑图并确认，再确定图表、写段句；主体确认后写摘要，随后分节修改及实际LaTeX编译。
3. 图、面板、实验模块、数据集和独立队列分别计数。全库未完成不阻止交付可执行流程，未知数量不能冒充一区标准。
4. 参照只迁移功能，不抄图句。正文不泛化自我否定；真实反证和适用边界保留。
5. 提示词及审计与投稿内容分开，工具使用按期刊要求披露。
6. 使用 [任务卡](../../templates/project.md)、[门禁表](../../templates/gates.csv)、[主张台账](../../templates/claim-ledger.csv) 和 [工作量表](../../templates/workload.csv) 记录阶段与证据。私人材料不提交公开仓库。
7. 阶段 5 运行 `checks/manuscript_audit.py`（占位、引用键、数字溯源三项硬门禁）与 `checks/reference_identity.py`（Crossref 身份核对），以退出码为准，不以自述为准。术语漂移与单位改写是提示项，须人工裁定后登记。
8. 数字可追溯不等于主张成立：未做统计比较不能写"无显著差异"，来源内部冲突须保留双方，分析集分母必须披露。这几类缺陷不含数字或数字正确，只能靠主张台账逐条核验，脚本替代不了。
9. 每批产出作者可读成果；按 [维护规范](../../CONTRIBUTING.md) 更新，不以状态日志替代交付。
